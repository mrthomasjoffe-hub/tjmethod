AI engine

Turn on the long-form draft that sits underneath a completed read.

This is a per-browser setting. Everything below is stored in this browser’s local storage and nowhere else. It is not part of the site, it is not shared with anyone who visits, and no key or answer is sent to any server except the engine you choose here.

Visitors who haven’t configured an engine see the scored read exactly as it is today. Nothing about their experience changes.

A local model only runs where it is installed. localhost in a browser means that visitor’s own machine — so Ollama drafts reads for you, on your laptop, and not for anyone else. To offer local drafting to visitors you would need to put Ollama behind a proxy on a machine that stays online.

Preferred engine
Ollama

The default is right for a standard local install. If you open this page over https, Ollama also needs OLLAMA_ORIGINS set to allow this site.

Structured output needs a reasonably capable model — 8B or larger. Anything smaller tends to return malformed JSON.
